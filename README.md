# Word by word

Тренажёр английской печати с контекстным переводом. Перед каждым предложением нужно напечатать выбранное слово **15 раз**, подтверждая каждое повторение Enter. Затем — предложение целиком. Ошибочные символы не попадают в поле, но учитываются в точности.

## Запуск

Нужен Python 3. В корне проекта:

```sh
python -m http.server 5173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:5173. Двойной щелчок по `index.html` не подходит: браузер должен загрузить JSON по HTTP. Сборка, установка npm-пакетов, сервер приложений и API-ключи не нужны. Node.js требуется только для тестов.

## Возможности

- Контекстный перевод под английскими словами/смысловыми группами и полный естественный перевод.
- Синхронная подсветка текущего слова и соответствующих частей русского перевода, в том числе при возврате Backspace.
- 200 английско-русских пар Tatoeba с проверенными соответствиями. Уровни B1/B2 — редакционная оценка языковых конструкций и лексики, не официальная классификация корпуса.
- Автоматический выбор слова: сначала слова с ошибками, затем с меньшим числом повторений. Используется форма слова из предложения.
- Очередь без повторов до исчерпания уровня. Смена уровня начинает новую очередь и заменяет незавершённое задание; накопленная статистика сохраняется.
- Светлая/тёмная темы и полностью скрываемая клавиатура US QWERTY с подсветкой физических нажатий.
- Локальное сохранение этапа, текста, повторений, очереди и статистики. Состояние восстанавливается после перезагрузки; время отсутствия не учитывается.
- Адаптивный интерфейс и поддержка экранной клавиатуры телефона. Вставка, перетаскивание, автозамена и массовый ввод не засчитываются.

Скорость рассчитывается только для текущего предложения: число принятых символов в поле / 5 / активное время в минутах. Backspace уменьшает число символов, но не стирает историю попыток. Точность — правильные попытки / все попытки ввода символа. Показатели разминки ведутся отдельно. Таймер запускается первым символом, приостанавливается при уходе из поля/окна или скрытии вкладки; ожидание Enter после разминки не переносится в статистику предложения.

## GitHub Pages

1. Создайте репозиторий и загрузите содержимое проекта, включая `data/`, `.nojekyll`, HTML, CSS и JavaScript.
2. Откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните и дождитесь публикации. Адрес обычно выглядит как `https://USERNAME.github.io/REPOSITORY/`.

Пути относительные, поэтому сайт работает и в корне домена, и в подпапке репозитория. GitHub Pages размещает только статические файлы; Python-скрипты запускаются разработчиком локально. Внешние запросы во время практики отсутствуют; это не устанавливаемое офлайн-приложение, для первоначального открытия нужен доступ к сайту.

## Материалы и лицензии

Источник предложений и прямых переводов: [Tatoeba](https://tatoeba.org/). Тексты доступны по [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/), отдельные предложения могут быть CC0. Для каждого оригинала сохранены идентификатор и ссылка; ссылки доступны в интерфейсе в разделе «Источники» и в JSON. Указание ссылки на страницу оригинала — предусмотренный Tatoeba способ атрибуции. Авторы указаны, когда они присутствовали в исходной выгрузке.

Английские и русские оригиналы сохранены без переписывания. Пословные пояснения — редакционные адаптации: один блок может объединять выражение, служебное слово может поясняться как «артикль» или «вспомогательный глагол». Подстрочник не следует читать как самостоятельное русское предложение.

## Обновление базы

Скачайте официальные таблицы `sentences.csv` (или `sentences_detailed.csv`) и `links.csv` со страницы https://tatoeba.org/en/downloads. Распакуйте архивы; `.bz2` также читаются напрямую.

```sh
python scripts/import_tatoeba.py --sentences sentences.csv --links links.csv --output data/candidates.json --limit 1000
```

Скрипт читает только прямые связи английского и русского, фильтрует длину и исключает повторяющиеся пары. Большая полная выгрузка требует памяти для хранения английских и русских строк. Для точечной подготовки также сохранён вспомогательный `fetch_tatoeba.py`, использующий текущий поисковый endpoint Tatoeba; это необязательный инструмент, endpoint может меняться.

Перед публикацией каждой пары необходимо проверить естественность и смысл перевода, назначить уровень, разметить группы и содержательные слова. Не публикуйте сырые результаты импорта. Редакторская разметка стартовой базы находится в `data/reviewed.json`; `scripts/build_corpus.py` собирает её в готовую базу и проверяет, что фрагменты точно совпадают с оригиналами.

Формат `data/sentences.json`: `version`, `sentences`. Каждое предложение содержит `id`, `en`, `ru`, `level`, `source`, `groups`, `candidates`. `groups[].en` — полуоткрытый диапазон индексов английских токенов, `groups[].ru` — индексы соответствующих русских токенов, `gloss` — контекстное пояснение. Токен — непустой фрагмент, отделённый пробелами; пунктуация принадлежит токену. `candidates` указывают английский индекс, точную форму без внешней пунктуации и перевод. Служебные слова связываются с русской смысловой группой; разные английские группы могут ссылаться на один русский фрагмент.

```sh
python scripts/build_corpus.py
python scripts/validate_data.py
npm test
```

При изменении схемы сохранений нужно увеличить версию и добавить миграцию или понятное уведомление о начале новой практики. При обновлении корпуса сохраняйте идентификаторы; несовместимое сохранение отвергается безопасно. Хранение — только в данном браузере, без облачной синхронизации. Не открывайте несколько одновременно активных тренировок в разных вкладках: они используют одно локальное сохранение.

## Структура

- `index.html`, `styles.css`, `app.js` — интерфейс и события браузера.
- `engine.js` — проверка ввода, очередь, выбор слова, метрики и проверка сохранений.
- `data/` — атрибутированный корпус и редакторская разметка.
- `scripts/` — подготовка и проверка данных; `tests/` — тесты поведения.

Доступность: видимый фокус, подписи полей, `aria-live` для обратной связи, системные шрифты, отсутствие внешних шрифтов/трекеров и отключение анимаций при `prefers-reduced-motion`.
